A personal pile of general-purpose AI slop — the agent skills I actually kept.

This is a junk drawer, not a product. Everything here is written for my own workflows,
gets changed without warning, and carries no promise of stability, backward
compatibility, or good taste. Copy freely; expectations, not so much.

Each skill is a directory with a `SKILL.md` following the
[Agent Skills specification](https://agentskills.io/specification), so it works in any
agent that reads that format — Claude Code is what I use, but nothing here is locked to
it. The pages below are generated from those same files, which means they cannot drift
from what you actually install.
